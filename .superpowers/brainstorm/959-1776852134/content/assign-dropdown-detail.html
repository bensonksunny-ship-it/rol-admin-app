How the data flows
Source: Each Sunday, the Sunday Ministry team saves names to sunday_reports → secondWeekAttendeesNames[]
Week count: We query the last 8 Sunday report documents and count how many times each name appears
Cross-check: Names are compared against all cell group members globally — anyone already in a cell is excluded
Assign action: Calls addCellGroupMember(cellId, { name, status: 'active' }) — person appears in cell's fellowship list immediately
Auto-refresh: The next Sunday when the report is saved, the list updates automatically — no cron needed
